- Ce que je connais déjà de Git : commit, add, push pull, 

Ce que j'attends de cet atelier : J’attends de cet atelier d’apprendre à utiliser Git, GitHub et Codespaces pour mieux travailler en équipe, gérer mes versions et collaborer efficacement sur un projet.
1. Juste après git commit, le commit se trouve dans le dépôt Git local de ton Codespace. Il n’est pas encore sur GitHub et les autres membres ne peuvent pas le voir.

2. Juste après git push, le commit est envoyé sur le dépôt GitHub de l’équipe. Les autres membres peuvent alors le récupérer avec git pull.

3. Si tu supprimes ton Codespace après un commit mais sans faire git push, ton commit est perdu avec le Codespace (sauf autre copie locale ou sauvegarde). Il faut donc penser à faire git push pour sauvegarder son travail sur GitHub.
