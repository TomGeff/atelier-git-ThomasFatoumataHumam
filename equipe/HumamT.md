## Quiz

1. Juste après `git commit`, où se trouve mon commit ?
- Mon commit est uniquement dans mon Codespace (historique local). Il n'est pas encore sur GitHub.

2. Juste après `git push`, où se trouve-t-il ?
- Il est sur GitHub, dans le dépôt de l'équipe.

3. Que se passe-t-il si je supprime mon Codespace après un commit mais sans push ?
- Si je supprime mon Codespace après un commit mais sans push, le commit est perdu : il n'existait que dans ce Codespace.
